# JARA — Sitio web

Sitio web de fotografía de JARA. Estático, sin base de datos ni servidor.

## Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | Landing con el formulario/encuesta que envía a WhatsApp. Página de inicio. |
| `portafolio.html` | Portafolio: 4 colecciones (Conciertos, Retratos, Campañas, Films) y 7 secciones. |
| `portafolio-beige2.html` | Vista previa de color, no forma parte del sitio publicado. |
| `img/` | Fotografías optimizadas para web. |

## Web publicada

Se publica con GitHub Pages. La URL aparece en **Settings → Pages** una vez activado.

## Notas

- El número de WhatsApp está en `index.html`, línea `WHATSAPP_NUMBER`.
- Más detalle de estructura y mantenimiento en `LEEME.txt`.
